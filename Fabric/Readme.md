### Synapse VS code extrension
- [Synapse VS code extension](https://marketplace.visualstudio.com/items?itemName=AzureSynapseAnalytics.synapseanalytics) is a Visual Studio Code extension that provides a lightweight, cross-platform, and keyboard-focused authoring experience for Azure Synapse Analytics. It provides a set of features that enable you to interact with your Synapse workspaces, develop scripts, and submit Spark jobs.
